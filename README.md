# FRONTIER STUDIO

Публичный сайт независимой цифровой студии:  
https://spowickj.github.io/Spowickj.frontier.studio/

## Страницы
- `index.html` — главная, услуги, портфолио и контактная форма.
- `about.html` — подход и принципы студии.\n- `privacy.html` — описание передачи сообщений через сторонний сервис формы.
- `drip.html` — демонстрационный концепт магазина с фильтрами и корзиной.
- `projects/frontier.html` — описание концепта FRONTIER.
- `projects/drip.html` — описание концепта DRIP.

## Портфолио
FRONTIER и DRIP — концептуальные проекты, созданные для демонстрации дизайна и интерфейсных решений. Они не являются подтверждёнными клиентскими заказами.

## Публикация
Сайт размещён на GitHub Pages из ветки `main`, корневая папка репозитория.

После изменения файлов GitHub Pages может потребоваться несколько минут для публикации.
